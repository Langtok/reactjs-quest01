# Welcome to Reactjs Quest01
***

## Task
This exercise are intoduction to react, the goal of this exercise is to create a React application with the following tasks:

1. Replace the default message "Edit src/App.js and save to reload. with Greeen!" inside a 'div' with the class 'title'
2. Remove the "Learn React" link.
3. Change the background color of the app to `#66CC00'.

The challenge lies in understanding the structure of a React application, 
working with JSX, and applying custom styles using CSS.

## Description
To solve the problem:
1. We created a React app using 'npx create-react-app .'
2. Edited the 'src/App.js' file to replace the default content and removed the "Learn React" link.
3. Updated the 'src/App.css' file to apply the new background color.

This exercise introduces the basics of React component rendering and styling.

## Installation
There is no much installation for this project exercise, 
just make sure node.js is installed in your computer if you want to run locally

## Usage
After creating the react files with "npx create-react-app ."
change the port number in the package.json file to:  "start":"cross-env PORT=8080 react-scripts start,"
Run the server by using this command: "npm start"
